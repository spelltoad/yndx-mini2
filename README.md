## Краткий результат

- DT: `Yandex Station Mini 2`, `yandex,station-mini2`, `amlogic, axg`.
- Linux `4.9.68 aarch64`; системные BusyBox и maind — ELF32 ARM. Не путать архитектуру ядра с ABI программы.
- Buildroot `2020.02.1`, quasar `3.21`.
- Найдены Dropbear, Entware, yse и работающий yamd; присутствуют init-скрипты SSH и YAM. Файл yamd совпадает по SHA-256 с релизом **YAM v0.1.18**.
- yse декларирует **0.4.0**, Dropbear — **2026.94**. Индивидуальные параметры доступа исключены из публичной вики. Каталог плагинов работающего YAM пуст на момент проверки.
- По подтверждению владельца: **часов нет**, внешней копии OTA-бэкапа нет. Радужная подсветка подтверждена как замена трёх штатных `.led`-паттернов; локальный RGB-бэкап найден.
- OTA: updatesd отсутствует в launch.json, applier заменён заглушкой, OTA-ключ отличается от локального бэкапа. Это признаки отключения OTA, **не испытание устойчивости ко всем обновлениям**.
- LED: 6 RGB-зон, max_brightness 255. Центр панели переключает play/pause; фиолетовая реакция есть в обоих направлениях, но отсутствует при voice playback. Офлайн-код кнопочного `handlePlayPause` подтверждает выбор ID `player_continue`/`player_pause`; полный runtime-путь до конкретного файла/LED ещё не проверен.
- `/` сейчас read-only. **Это не защищает от изменения `/data`, `/tmp`, sysfs или управления сервисами.**

## Публичная вики и локальные данные

Адрес устройства, параметры подключения/аутентификации и точный индивидуальный путь бэкапа хранятся только в `private/device.local.md`, исключённом из Git. **В клоне с GitHub этого файла не будет.** Для работы со своим устройством запросите параметры у его владельца; placeholders в документации не исполнять буквально. Общие предупреждения о безопасности, стандартные порты, версии и хеши прошивки сохранены.

В репозиторий не входят бинарник maind, Python-окружение и промежуточные дампы. Скрипты анализа работают только с отдельно полученным локальным артефактом. Правила для агентов — в AGENTS.md.

## Статусы знания

- `observed` — получено диагностикой этого экземпляра; ссылка на свидетельство обязательна.
- `upstream` — утверждение внешнего источника; не считается проверкой устройства.
- `inferred` — вывод из фактов, с указанием оснований и ограничений.
- `unknown` — неизвестно; не подменять догадкой.

Этот репозиторий описывает конкретный экземпляр и общие механизмы отдельно. Команды установки из внешних источников **не являются разрешением на выполнение**. Изменений на колонке в рамках исследования не выполнялось; SSH и работа штатных демонов могут оставлять собственные журналы и менять текущее состояние.
