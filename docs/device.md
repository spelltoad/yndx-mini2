`armhf` указан upstream; первые 20 байт ELF подтверждают ELF32 ARM, **не отдельно float ABI**. Ядро aarch64 не означает 64-битный системный userspace. Пакетная БД Entware указывает aarch64-3.10; это отдельное окружение, а не ABI системного maind.

## Хранилище

| MTD | Имя | Размер, hex |
|---|---|---|
| mtd0 | bootloader | 00200000 |
| mtd1 | tpl | 00200000 |
| mtd2 | boot | 00a00000 |
| mtd3 | system | 05000000 |
| mtd4 | nv | 00100000 |
| mtd5 | bkupgrade | 06940000 |
| mtd6 | recovery | 031c0000 |

Erase size всех перечисленных MTD — `00020000`. Данные observed E02.

- `/`: `ubi0:rootfs`, ubifs, **ro**; df: 64.8M, свободно 11.2M.
- `/bkupgrade`: `/dev/ubi1_0`, ubifs, **rw**; df: 87.5M, свободно 67.3M.
- `/data -> /bkupgrade/data`.
- `/opt -> /data/opt/entware`.
- `/tee`: `/dev/mtdblock4`, vfat, ro. Содержимое не читалось.
- `/tmp`, `/run`, `/dev/shm` — tmpfs. Свободное место и mount flags — моментальный срез, не постоянная гарантия.

| SSH | Dropbear ELF32 ARM, встроенная версия 2026.94; параметры init/процессов проверены, индивидуальные сведения вынесены в private (E07–E08) | происхождение сборки, отдельный тест аутентификации, сохранность после reboot |

| YAM | файл совпадает с asset v0.1.18 (E06); S99yam; фактический data-dir /data/quazar/yam/data; plugins пуст (E07–E08) | порт/API, настройки, auto-update |

Путь YAM — **quazar** через z; основной стек использует **quasar** через s. Не нормализовать эти имена. Наличие init-скрипта не заменяет тест перезагрузки (он не разрешён и не выполнялся).

OTA-признаки согласуются с `yandex-noupdate.sh` (S5), но идентичность локального скрипта текущему upstream не проверена. В `/data/opt/backup` есть три .orig; внешний бэкап и валидность восстановления неизвестны.

## История и периферия

Владелец подтвердил: **часов нет**, установлены OTA-защита, автозапуск SSH, радужный скрипт и YAM; внешнего OTA-бэкапа нет. Подробности: [E04–E06](evidence/002-yam-provenance.md).

Страница модели (S2) описывает ES8156 + SY6045S, кольцо 6 RGB-зон, LED-часы IS31FL3236, LTR-308, DS1307 и AW96103. Это upstream-описание вариантов модели, **не подтверждённый состав нашего экземпляра**. Видимые часы отсутствуют со слов владельца; драйверы/узлы часов ещё не исследованы. Никаких I2C-проб, изменения LED, захвата микрофона или воспроизведения не было.

YAM v0.1.18 идентифицирован по совпадению хеша с GitHub asset digest. Фактический data-dir подтверждён выбранным аргументом процесса; plugins пуст, включая скрытые записи. yse декларирует 0.4.0, Dropbear содержит версионную строку 2026.94. Радуга — замена трёх штатных паттернов, не отдельный фоновый сервис. Подробности, риски и хеши: [E07–E08](evidence/003-modifications.md).

## Риски для дальнейшей работы

- Нельзя считать OTA Яндекса и самообновление YAM одним механизмом: upstream описывает отдельный updater yamd; локальная настройка неизвестна.
- Индивидуальные параметры безопасности SSH вынесены в игнорируемый private/device.local.md. Upstream предупреждает о рисках SSH с пустым паролем, сетевого ADB и YAM Web UI без авторизации. Не открывать сервисы в интернет; метод аутентификации нужно проверять для каждого экземпляра.
- Сброс может удалить /data, включая софт и локальный бэкап (upstream S3). Не использовать reset как диагностику.
